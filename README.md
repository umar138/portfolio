
# Umar Farooq — Professional Portfolio
## CSC 337 | Web Programming Languages | Assignment No. 1

A professional, responsive, four-page personal portfolio website developed using HTML5 and CSS3 for the CSC 337 course at Iqra University, Islamabad Campus.

The portfolio introduces my education, personal interests, Data Engineering career goals, favourite media and contact information.

## 1. Project Overview

The purpose of this project is to demonstrate my understanding of HTML5 structure, semantic elements, CSS styling, page layouts, responsive web design and website publishing.

My portfolio represents me as a BS Computer Science student with a strong interest in Data Engineering.

## 2. Technologies Used

- HTML5 — Website structure and content
- CSS3 — Styling, layouts and responsive design
- Flexbox — Navigation and flexible layouts
- CSS Grid — Multi-column page layouts
- CSS Positioning — Sticky navigation and floating elements
- Google Maps — Embedded location map
- YouTube — Embedded videos
- Git and GitHub — Version control and project hosting
- GitHub Pages — Live website deployment

No JavaScript or downloaded website templates have been used.
